# 像素画站 — 站点画像(品牌名思考输入)

## 一句话定位
一个聚焦 minecraft/复古游戏像素画的**在线转换器 + 创作资源站**。纯前端无 AI,把图片快速转像素画,配教程/模板/灵感集。

## 核心功能
- 图片转像素画(Canvas color quantization,纯前端,无 AI API,成本≈0)
- 多调色板 / 像素大小 / 导出格式
- minecraft 方块风转换
- 像素画灵感 / 模板 / 教程(内容,吃信息意图流量)

## 战略定位
- SEO 工具站 + 品牌词沉淀(路径A,你选的)
- **工具+内容混合**(金矿词全是信息意图,纯工具页吃不到流量)
- 长期:把品牌名做成"像素画转换"的品类代名词

## 目标受众
- **minecraft 玩家/创作者**(核心动力,与主搜索词高度重合)
- indie 游戏开发者(sprite/复古风)
- 数字创作爱好者(教育/课堂/DIY)
- 复古/怀旧审美人群
- 信息意图为主:找工具+教程+灵感,**非纯交易**

## 差异化(凭什么赢)
1. **聚焦 minecraft/复古游戏像素画**(实测金矿;通用像素化被 Canva/Adobe 占)
2. **工具+内容混合**(每页工具+教程+示例图,匹配信息意图 SERP 的"评价/图片包/站点子链")
3. **纯前端无 AI**(低成本/隐私/快/像素尺寸准确——pixelartvillage 也是 "without AI" 卖点)
4. **品牌化**(长期资产,非关键词域名)

## 流量入口(实测金矿,Semrush)
- minecraft pixel art(8,100 / KD19)及簇 4 词 ~9,900 月搜
- pixel art ideas(9,900 / KD28)
- image to pixel art(4,400 / KD46)、pixel art converter(2,900 / KD49)通用
- 抛弃:game boy / 8-bit / 16-bit / sprite(全 0 量)

## 变现
- Google AdSense(纯前端低成本,单位经济为正)
- 天花板参照:pixelartvillage 27.7 万 / ~$800 月入

## 竞品参照
- **pixelartvillage.com**(头部 27.7 万,品牌名,AS20 新域名短期做到,"without AI" 卖点)
- 差异:它偏纯工具,你聚焦 minecraft + 内容

## 品牌名应传达的特质
- 像素画 / 复古游戏美学
- 转换 / 创造动作
- 聚焦 / 专业 / 工具感
- 品牌感(好记 / 好拼 / 独特)

## 起名词根方向(供思考,不替你想)
- **品类暗示**:pixel, bit, dot, block, retro, art, craft, vox(el)
- **动作/场所**:make, convert, forge, lab, studio, works, base, hub, village, den
- **调性选项**:
  - 复古游戏风(minecraft/8-bit/retro 感)
  - 创作工具风(studio/lab/works)
  - 社区风(village/hub/den)
- **参照名**:pixelartvillage, aseprite, piskel, pixilart(都是品牌名,非 EMD)

## 避免
- ❌ 纯关键词域名(`imagetopixelart.com`)— spam 信号,限制品牌化
- ❌ 纯抽象(`zorvix.com`)— 早期无品类暗示
- ❌ 连字符 / 数字
- ✅ `.com` 首选;`.art` 备选(品类契合 + 好注册)
- ✅ 注册前查域名历史(Wayback + `site:` 搜),别踩被惩罚过的二手域名
